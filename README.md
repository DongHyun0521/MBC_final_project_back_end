**LOMBOK 적용 방법**  
1-1. C:\Users\사용자이름\.m2\repository\org\projectlombok\lombok\버전\ **lombok-xxx.jar 실행**  
1-2. 왼쪽 하단의 **[Specify location...]** 버튼 클릭  
1-3. **SpringToolsForEclipse.exe** (SpringToolSuite4.exe) 선택  
1-4. 우측 하단의 **[Install / Update]** 버튼 클릭  
1-5. **SpringToolsForEclipse** 다시 실행  
1-6. **Project ➔ Clean**  

2-1. C:\Users\사용자이름\.m2\repository\org\projectlombok\lombok\버전\ **lombok-xxx.jar 복사**  
2-2. C:\sts-5.0.1.RELEASE\ 로 이동 후, **lombok.jar 붙여넣기** (SpringToolsForEclipse.exe와 lombok.jar 나란히)  
2-3. **SpringToolsForEclipse.ini** 메모장으로 실행  
2-4. 맨 아랫줄에 **-javaagent:lombok.jar** (-javaagent:C:\sts-5.0.1.RELEASE\lombok.jar) 붙여넣기  
2-5. **SpringToolsForEclipse** 다시 실행
